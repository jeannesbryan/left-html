About

What this template is, and the two or three things worth knowing before you start cutting it up.

This is the static-page view of the Left interface, rendered as plain HTML. It exists so the design can be lifted into a project that is not HTMLy — a documentation site, a landing page, a generated static build — without transliterating PHP by hand.

What Left provides

Two layers, kept deliberately separate:

  • Marx — a classless CSS reset. It styles the elements you would otherwise have to remember to style: headings, lists, tables, quotes, form controls. It is unopinionated about colour.
  • Left — the red-and-gold editorial skin on top: the gold banner, the paper background, the card treatment with a red left edge and an offset shadow, the serif display type, the footer.

Because the bottom layer is classless, ordinary markup already looks deliberate. Left's classes are then for the things that are genuinely structural — a post card, a hero, a widget — rather than for every paragraph.

The classes you will actually touch

ClassWhat it is
.left-widthThe page container. Sets the measure.

.left-panelShared card for related posts, navigation, comments.
.left-eyebrowSmall uppercase label above a heading.
.left-metaThe date · read time · category line.

Customising it

Colour lives in a single :root block at the top of assets/left.css. Change the two reds and the gold and the whole interface follows, because nothing downstream hard-codes a colour.

:root {
  --left-red:   #b91c1c;
  --left-gold:  #facc15;
  --left-paper: #fff9e8;
}

Everything else in that file is layout, and is safe to edit.

Two caveats

  • The three pages repeat the header and footer verbatim. That is intentional — a template that needs a build step to render is no longer a template — but it does mean a change to the navigation has to be made in three places.
  • The asset links carry no cache-buster. If you add one, derive it from the file rather than typing a version number, because a version number on a URL is a promise that has to be kept by hand.
